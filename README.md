This domain is dead on purpose. Brush & Broom lives at [brushnbroom.com](https://brushnbroom.com).

Do not put real pages here. Do not restore DNS unless you only want a redirect.

## Current state

- Repo is redirect stubs only.
- DNS for `brushandbroomllp.com` does not resolve. Leave it that way if you want the name gone.
- If the registrar still owns the name and you want old links to work, point both apex and `www` at this GitHub Pages repo so these stubs can send people to brushnbroom.com.

## What you still have to do outside GitHub

1. Google Search Console: add/keep only `https://brushnbroom.com`. Remove the old-domain property when Google lets you.
2. Registrar: either let `brushandbroomllp.com` expire, or set a 301 forward to `https://brushnbroom.com`.
3. Google Business Profile, Nextdoor, BBB, MapQuest: website field must be `https://brushnbroom.com` only.
4. Do not submit a sitemap for the old domain.
